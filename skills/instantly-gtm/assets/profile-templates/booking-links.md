# Booking links

- **Primary booking link:** <https://cal.com/… or https://calendly.com/…>
- **Meeting type / length:** <e.g. "15-min intro">
- **Backup / round-robin (optional):** <second link, if any>

## CTA phrasing (use verbatim so it matches the user's style)
- **In cold email:** <e.g. "worth a quick 15 minutes? grab a time here: {{link}}">
- **In a reply to an interested lead:** <e.g. "great, here's my calendar: {{link}}, or send a couple of times that work">

> If no booking link exists, the CTA defaults to "reply to this email", never invent a URL.
